## 1. Коротко

- **Мы не запрашиваем имя, email или пароль.** Традиционной регистрации нет. «Аккаунт» — это непрозрачный API-ключ, выдаваемый после оплаты.

- **Фрагменты вашего кода отправляются стороннему AI-провайдеру для анализа.** Это суть работы Drydock — подробно в разделе 3.
- **Сейчас нет кнопки самостоятельного удаления данных.** Напишите нам на почту — обработаем запрос вручную (раздел 7).

| Данные | Описание |
|---|---|
| Находки аудита | Для каждого аудита: оценка и список находок — путь файла, номер строки, заголовок, объяснение, для секретов — маскированный превью (например `AKIA****(20 chars)`) вместо самого значения. |

### 2.3 Что логируется автоматически

- IP-адрес используется кратковременно, в памяти, для ограничения частоты запросов. **В базу данных не пишется.**
- Cookies не используются. В браузере локально хранится выбор темы (светлая/тёмная) и, на время открытой вкладки, ваш API-ключ и текущий результат аудита — эти данные остаются только в браузере и никогда не передаются нам как «аналитика».

## 3. Ваш код и анализ сторонним AI — самое важное

При запросе аудита Drydock **не** отправляет никому весь ваш репозиторий. Вот что происходит:

1. Код читается в память (из загруженного zip или скачанного по указанному вами публичному GitHub URL). На этом шаге на диск ничего не пишется.
2. Отфильтровываются нерелевантные файлы (`node_modules/`, `.git/`, сборочные артефакты) и остаются только типы файлов исходного кода, релевантные рубрике аудита (сейчас — аутентификация и общая безопасность).
3. Из оставшихся файлов отбираются только те, чей путь или содержимое совпадает с ключевыми словами, релевантными безопасности.
4. Каждый выбранный файл обрезается до максимального размера, а суммарный объём кода на один аудит ограничен, прежде чем отправляется языковой модели для анализа.
5. **Мы храним только ответ модели — находки.** Буквальные фрагменты кода, использованные для внутренней проверки находки, не сохраняются в базу данных.

**Кто получает эти фрагменты кода:** Drydock использует AITunnel (прокси LLM API) как основного провайдера, с прямым подключением к Anthropic API как запасным вариантом. Оба обрабатывают фрагменты кода исключительно для формирования результата аудита; мы не контролируем и не видим их собственные политики хранения данных сверх того, что они публикуют сами — рекомендуем ознакомиться с ними при наличии особых требований.

**Практическое следствие:** если в вашем коде есть действующий секрет (API-ключ, пароль и т.п.), его *значение* попадает во фрагмент, отправляемый AI-модели для обнаружения, но **никогда не сохраняется** Drydock впоследствии — хранится только маскированный превью. Если аудит нашёл реальный секрет, считайте его скомпрометированным и ротируйте его независимо от того, что хранит или не хранит Drydock.

Если такой поток данных не подходит для вашего случая (например, приватная высокочувствительная кодовая база) — не используйте Drydock для аудита такого кода.

## 5. Сколько мы храним данные

Результаты аудитов, платёжные записи и записи подписок сейчас хранятся **бессрочно** — у нас пока нет автоматического графика удаления. Временные рабочие каталоги для сборки Fix Pack и превью-окружения удаляются автоматически (превью истекают и очищаются по расписанию, как правило в течение нескольких часов).

Мы работаем над формальными сроками хранения; до этого вы можете запросить удаление вручную (раздел 7).
